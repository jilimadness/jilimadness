# 🎰 JiliMadness

Welcome to **JiliMadness** — a fun project combining GitHub Pages with Firebase to create a bold, interactive site.  

## 🚀 Features
- 🔑 Free hosting via GitHub Pages  
- 🔥 Firebase integration for database and signup  
- 🎨 Bold promotional design inspired by gaming sites  
- 📱 Mobile-friendly signup form  

## 🛠 Tech Stack
- HTML / CSS / JavaScript  
- Firebase (Firestore + Authentication)  
- GitHub Pages  

## 📈 Roadmap
- ✅ Basic signup form with Firebase  
- ✅ User list display from Firestore  
- 🔄 Real-time updates with Firestore listeners  
- 🎁 Points and rewards system
